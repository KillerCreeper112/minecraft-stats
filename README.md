## Overview

This website was made to read and gather data from my server, uSurvive.
Through the navigation bar, you can switch between viewing all of the players who have joined the server or view all of the shop data to see how many times an item has been bought or sold.

This is my first time building a website using Spring Boot and ReactJS. It has helped me gain a general understanding of REST APIs, frontend/backend integration, and database management.
